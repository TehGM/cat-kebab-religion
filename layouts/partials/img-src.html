{{- /* A URL for one sacred image. Every on the site goes through here, so there is one place to decide what is actually served. {{ partial "img-src.html" (dict "file" "Screenshot_51.png") }} {{ partial "img-src.html" (dict "file" $f "original" true) }} `file` takes a bare filename or a /img/cat/… path, so front matter and shortcodes can carry either. With `webp = true` under [params.images], every image is served as WebP — article illustrations, the wall's thumbnails, the masthead roundel. Pass `original` for the file untouched: the popup and the reveal show the record as it was filed, and the favicon stays in a format every browser takes for one. Stills are converted here, by Hugo, during the build. Animations cannot be: Hugo's pipeline decodes the first frame of a GIF and nothing else, so converting one would silently replace a moving image with a still. So animated WebP is looked for rather than made. Anything that drops `.gif.webp` into assets/img/derived/ before `hugo` runs will be picked up here — the deploy workflow does this with ffmpeg. A build without that step (a local one, say) finds nothing and quietly serves the GIF, which is correct: heavier, but moving. It does not warn, since the strict build would fail on it; the deploy step fails by itself if ffmpeg does. See the README. */ -}} {{- $name := path.Base (.file | default "") -}} {{- $original := .original | default false -}} {{- $convert := and (not $original) site.Params.images.webp -}} {{- $url := "" -}} {{- with resources.Get (printf "img/cat/%s" $name) -}} {{- $out := . -}} {{- $ext := lower (path.Ext $name) -}} {{- if and $convert (ne $ext ".webp") -}} {{- if eq $ext ".gif" -}} {{- with resources.Get (printf "img/derived/%s.webp" $name) -}} {{- $out = . -}} {{- end -}} {{- else -}} {{- $out = .Process "webp q82" -}} {{- end -}} {{- end -}} {{- $url = $out.RelPermalink -}} {{- else -}} {{- warnf "img-src: no image named %q in assets/img/cat/" $name -}} {{- $url = $.file | relURL -}} {{- end -}} {{- return $url -}}
